OpenBhasha Annotation UX

Guidelines
Noise Tagging

Use @ to insert background or ambient sound tags.

Examples: @noise, @background-laughter, @cough

Code-Mixing

Wrap native text in [ ] and its Latin transliteration or English equivalent in ( ).

Examples: [ट्रेन](train), [स्टडी](study)

Entity Tagging

Use # to mark named entities. Select or type an entity type (e.g., PERSON, ORG, GPE, etc.), then wrap the entity text inside { } followed by () for optional notes or attributes.

Format: #EntityType{verbatim}()

Examples: #ORG{भारतीय रयिलवे}(), #ORG{स्टेट बैंक ऑफ इंडिया}(), #GPE{नई दिल्ली}(), #PERSON{नरेंद्र मोदी}()

Accent / Mispronunciation

Wrap mispronounced or accented words in < > and their normalized form in ( ).

Examples: <हमाये>(हमारे), <समझनाहीं>(समझ नहीं)
